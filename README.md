# Chronos Light (ЛР 1, Python + Pygame, вариант 3)

Лабиринт абсолютно тёмен. Игрок освещает его фонариком (конус alpha ± 30°).
Стены, на которые не падает свет, каждые 3 секунды сдвигаются на клетку в случайную
свободную сторону - структура лабиринта постоянно меняется.
Цель: дойти до зелёного выхода за 90 секунд.

## Запуск
    pip install -r requirements.txt
    python main.py

## Управление
WASD - движение, мышь - направление взгляда, F1 - показать тёмные стены,
ESC - в меню, ENTER - старт.

## Алгоритмы
- Конус света: 61 луч от игрока в секторе alpha ± 30°, шаг луча 2 px,
  первая встреченная стена считается освещённой и рисуется белым.
- Трансформация: счётчик в тени у каждой стены; через 3 с стена сдвигается
  в случайную свободную соседнюю клетку матрицы (рамка, выход и игрок защищены).

## Структура
main.py - цикл и состояния; constants.py - настройки; level.py - матрица и сдвиг стен;
light.py - конус света; player.py - игрок; ui.py - интерфейс.
